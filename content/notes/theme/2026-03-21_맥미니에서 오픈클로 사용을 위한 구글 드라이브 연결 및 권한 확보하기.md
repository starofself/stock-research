맥 기준으로 가장 쉬운 방법은 `Google Cloud에서 OAuth 앱 1개 만들기 -> gog 설치 -> OpenClaw에 다시 읽히기` 순서예요.  
중요한 점 하나만 먼저 말하면, 지금 OpenClaw는 패널에서 `Google Drive` 버튼을 누르는 방식이 아니라 `gog`라는 Google용 CLI를 붙여서 Drive를 쓰게 만드는 구조예요.

1. [Google Cloud Console](https://console.cloud.google.com/)에 들어가서 맨 위 `프로젝트 선택`을 누른 뒤 `새 프로젝트`를 만드세요.

2. 왼쪽 위 메뉴에서 `APIs & Services` -> `Library`로 가세요.  
`Google Drive API`를 검색해서 들어간 뒤 `Enable`을 누르세요.

3. 이제 `Google Auth platform` -> `Branding`으로 가세요.  
처음이면 `Get Started`를 누릅니다.  
`App name`은 아무 이름이나 넣고, `User support email`은 본인 메일로 고르세요.  
`Audience`는 개인 Gmail이면 `External`, 회사/학교 Workspace 내부만 쓸 거면 `Internal`을 고르세요.  
마지막에 체크박스 동의 후 `Create`까지 누르세요.

4. `Audience` 탭으로 가서 `Test users` -> `Add users`를 누르고, 실제로 로그인할 본인 Gmail 주소를 추가하세요.  
처음 테스트용이면 이 단계가 거의 꼭 필요합니다.

5. `Google Auth platform` -> `Clients`로 가서 `Create Client`를 누르세요.  
`Application type`은 꼭 `Desktop app`으로 고르세요.  
이름은 예를 들어 `OpenClaw Drive`처럼 넣고 `Create`를 누르세요.  
생성되면 `Download JSON` 버튼으로 `client_secret_....json` 파일을 받으세요.  
여기서 `Service account`를 고르면 안 됩니다.

6. 맥의 `터미널`을 열고 아래를 순서대로 실행하세요.

```bash
brew install gogcli
```

만약 못 찾는다고 나오면 이걸 쓰면 됩니다.

```bash
brew install steipete/tap/gogcli
```

7. 방금 받은 JSON을 `gog`에 등록하세요.

```bash
gog auth credentials ~/Downloads/client_secret_어쩌구.json
```

파일명이 길면 Finder에서 `Downloads` 폴더 열어서 파일명을 복사해 붙여넣으면 됩니다.

8. 이제 Drive 권한 인증을 시작하세요.

```bash
gog auth add 당신이메일@gmail.com --services drive
```

브라우저가 열리면:
`계정 선택` -> `고급` 경고가 뜨면 본인이 만든 테스트 앱인지 확인 -> `계속` -> `허용`
순서로 진행하면 됩니다.

9. 인증이 끝나면 연결 확인을 하세요.

```bash
gog auth list
gog drive search "test" --max 5
```

검색 결과가 나오면 Google Drive 연결은 된 겁니다.

10. 마지막으로 OpenClaw 패널로 돌아가서 오른쪽 위 `OpenClaw 데몬 다시 읽기` 버튼을 누르세요.  
그래도 바로 안 잡히면 새 세션을 열거나 OpenClaw를 한 번 다시 켜면 됩니다.

연결 후에는 OpenClaw에게 자연어로 `Drive에서 지난주 PDF 찾아줘` 같은 식으로 요청하면 되는 흐름이에요.  
참고: [gog quickstart](https://gogcli.sh/), [OAuth consent screen 설정](https://developers.google.com/workspace/guides/configure-oauth-consent), [Desktop app 클라이언트 만들기](https://developers.google.com/workspace/guides/create-credentials), [Drive 권한 범위 설명](https://developers.google.com/workspace/drive/api/guides/api-specific-auth)

원하면 다음 답에서 내가 이 맥 기준으로 `어느 화면에서 뭘 눌러야 하는지` 더 잘게 쪼개서, 아예 체크리스트처럼 같이 진행해줄게.
