## 핵심 개념
- Google Workspace CLI: 터미널 환경에서 구글 앱을 제어하는 인터페이스 / 반복 업무를 코드로 자동화할 수 있음
- AI 에이전트: CLI를 활용해 구글 워크스페이스를 다루는 주체 / 인간 대신 복잡한 문서 작업을 대신 수행함
- API 할당량(Quota): API 사용 시 정해진 시간 내 요청 횟수 제한 / 과도한 요청으로 인한 서비스 차단을 방지하기 위함
- OAuth 클라이언트: 서비스 사용을 위한 인증 절차 / 안전하게 사용자 데이터를 접근하고 제어하기 위해 필수적
