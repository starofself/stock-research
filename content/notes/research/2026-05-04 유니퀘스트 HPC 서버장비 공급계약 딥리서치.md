## 1. 핵심 결론

유니퀘스트는 원래부터 완제품 서버 제조사가 아니라, 비메모리 반도체/전자부품 유통·기술지원 기반의 솔루션 디스트리뷰터다. 다만 2024년 사업목적에 `기계장비 및 관련 물품 판매업`을 추가하면서 서버 장비 판매를 공식 신규사업으로 열었고, 2024년 Super Micro Computer 기반 서버 판매, ASUS 대리점 계약, 2025년 GPU Server 매출 확대를 이미 진행했다.

따라서 이번 1,288억원 HPC 서버장비 공급계약은 “전혀 없던 사업에 갑자기 진입”이라기보다는, 2024~2025년에 준비한 서버 유통/설치/유지보수 사업이 2026년에 대형 PO로 터진 사건이다. 다만 규모가 2025년 서버 관련 매출 약 292억원의 4.4배, 2025년 연결 매출 7,300억원의 17.64%라서 기존 사업 대비 의미는 매우 크다.

## 3. 원래 서버장비 공급하던 회사인가?

### 짧은 답

부분적으로는 맞다. 단, “서버 제조사”는 아니다. 2024년부터 해외 서버 제조사 대리점/공급·설치·유지보수 모델로 서버 사업을 키우기 시작했다.

### 근거

2025 사업보고서:
- 서버 사업은 서버 제조사와 대리점 계약을 맺고 서버 공급, 설치 및 유지보수를 지원하는 업무라고 설명.
- Super Micro Computer, ASUS 제품 중 GPU Server 중심으로 매출 확대 추진.
- 2025년 1~12월 서버 관련 매출 약 292억원.
- 서버 사업 확대를 위해 기술지원 1명 신규 채용, 향후 고객 지원 인원 추가 충원 예정.
- 신규 투자설비나 창고는 필요 없다고 명시.

2024 사업보고서:
- 기존 Super Micro Computer 외에 서버 판매 확대를 위해 ASUS와 대리점 계약 체결.
- 2024년 서버 관련 매출 46억원.
- 서버 TF 조직 구성, 데이터센터에 필요한 서버 제품군 공급 계획 언급.

따라서 타임라인은 다음과 같다.

- 2023년까지: 주력은 비메모리 반도체/전자부품 유통, 서버 사업은 본격 수치 없음.
- 2024년 3월: 사업목적에 기계장비 및 관련 물품 판매업, 상품 종합 도소매업 추가.
- 2024년: 서버 사업 매출 46억원 발생. Super Micro Computer 외 ASUS 대리점 계약.
- 2025년: GPU Server 중심 매출 약 292억원으로 확대.
- 2026년 5월: HPC 서버장비 1,288억원 공급계약 공시.

## 10. 투자 포인트

### 긍정

1. 서버 사업은 이미 2024년 46억원, 2025년 292억원 매출이 있었고, 이번 1,288억원 계약으로 스케일이 급격히 커짐.
2. 계약금액이 2025년 연결 매출의 17.64%로 단일 이벤트 효과가 큼.
3. 계약기간이 짧아 2026년 2~3분기 매출 인식 가능성이 높음.
4. Super Micro, ASUS GPU Server 중심 사업 추진 이력이 확인되어 AI 서버 테마와 연결 가능.
5. 제조 CAPEX 없이 기존 유통 프로세스를 활용하므로 자산 효율성은 좋을 수 있음.

### 부정/리스크

1. 계약상대 미공개. 반복 고객인지, 일회성 프로젝트인지 판단 불가.
2. 검수완료 후 전액 일시지급 조건. 납품/검수 지연 시 현금 회수 지연 가능.
3. 서버 장비 유통은 고매출 저마진 가능성이 높음. 영업이익 기여는 매출 증가율보다 훨씬 작을 수 있음.
4. GPU/서버 조달 가격, 환율, 납품 일정, 검수 기준에 따라 마진 변동 가능.
5. 2025년 서버 매출 292억원 대비 이번 계약은 4.4배라 운전자본 부담이 커질 수 있음.
6. 회사는 사업보고서에서 장기 수주가 미비하다고 설명해왔음. 이번 계약이 구조적 변화인지 단발성인지 후속 확인 필요.
7. 계약 종료일은 납품상황에 따라 변동 가능하다고 공시.

## 12. 최종 판단

이번 공시는 유니퀘스트가 원래 하던 반도체 유통에서 완전히 벗어난 사건은 아니다. 2024년부터 서버 장비 공급사업을 추가했고, 2025년에 이미 GPU Server 매출 292억원을 냈다. 다만 이번 1,288억원 계약은 기존 서버 사업 매출 대비 4.4배라 “서버 사업이 실제 대형 매출원으로 검증되는 첫 공시”에 가깝다.

투자 판단상 핵심은 매출이 아니라 마진과 반복성이다. 2026년 2~3분기 실적에서 매출만 커지고 영업이익이 적게 늘면 단순 저마진 장비 유통 이벤트로 볼 수 있다. 반대로 서버 사업 매출이 반복되고 영업이익률이 기존 5% 안팎 또는 그 이상으로 확인되면, 유니퀘스트는 AI/HPC 서버 유통·솔루션 업체로 재평가될 여지가 있다.
