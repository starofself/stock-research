# 옵시디언 클리핑 딥리서치 (지식 수집 및 요약 자동화 시스템)

> [!summary] 핵심 요약
> 시중에 판매되는 특정 프로그램의 이름이 아닙니다. **크롬 확장 프로그램(웹 클리퍼) + 인공지능(AI) + 옵시디언(메모 앱)**을 결합하여 개인이 스스로 구축한 '나만의 맞춤형 정보 요약 비서' 시스템을 말합니다.

<br>

## 📌 1. 이것은 무엇인가요?

유익하지만 너무 길거나 어려운 유튜브 영상, 혹은 복잡한 개발자 문서(깃허브 등)를 버튼 클릭 한 번으로 내 입맛에 맞게 완벽히 요약해서 옵시디언 노트에 저장해 주는 마법 같은 워크플로우입니다. 

단순히 정보를 복사해서 붙여넣는 스크랩을 넘어, AI가 방대한 내용을 소화한 뒤 내가 이해하기 가장 쉬운 형태로 가공해 주는 것이 이 시스템의 핵심입니다.

<br>

## 💡 2. 누가, 언제, 왜 만들었나요?

* **누가:** 화장품 회사에서 상품 기획을 담당하며 AI와 옵시디언을 깊게 공부하고 있는 '슬기' 님이 고안했습니다.
* **언제 & 어디서:** 2025년 12월 29일, IT 및 비즈니스 인사이트를 나누는 '평범한 사업가' 유튜브 채널(AI 팟캐스트 77화)을 통해 처음 소개되었습니다.

**제작 배경 (왜 만들었을까?)**

현대 사회에서는 유튜브나 웹사이트를 통해 하루에도 수십 개의 훌륭한 정보가 쏟아집니다. 하지만 외국어 영상이거나 전문 용어가 많아 당장 이해하기 벅차고, 영상이 너무 길어 끝까지 시청할 시간이 부족한 경우가 많습니다. '나중에 보기'에 저장해 두고 영영 열어보지 않는 일도 허다합니다.

이러한 현실적인 문제를 해결하기 위해, "이 어려운 내용을 내 지식 수준에 맞춰 쉽게 번역하고 요약해서, 내 업무에 바로 써먹을 수 있게 코칭까지 해주는 비서가 있으면 좋겠다"는 생각에서 출발해 만들어진 시스템입니다.

<br>

## ⚙️ 3. 어떻게 작동하나요?

시스템을 구축해두면 실제 사용 과정은 매우 직관적이고 단순하게 이루어집니다.

1. **정보 발견:** 평소처럼 인터넷을 하다가 유익한 유튜브 교육 영상이나 복잡한 기술 문서를 발견합니다.
2. **버튼 클릭:** 웹 브라우저 우측 상단에 설치해 둔 '옵시디언 클리핑' 버튼을 누릅니다.
3. **AI 분석:** 연결된 인공지능(Grok, Claude 등)이 해당 영상의 자막이나 웹페이지의 전체 텍스트를 순식간에 읽어 들입니다.
4. **노트 자동 생성:** AI가 내용을 딥리서치 및 분석한 뒤, 내가 미리 지정해 둔 템플릿(양식)에 맞춰 옵시디언 앱에 읽기 편한 문서 형태로 자동 생성해 줍니다.

<br>

## 📝 4. 노트에는 어떤 내용이 저장되나요? (가장 강력한 기능)

이 시스템의 가장 큰 무기는 내 입맛에 맞춘 '템플릿'입니다. 클리핑을 실행하면 노트에는 다음과 같은 알짜배기 정보들이 깔끔하게 구조화되어 담깁니다.

* **영상 원본 (Embed):** 언제든 다시 시청할 수 있도록 영상 원본 링크와 재생 화면이 노트 상단에 들어갑니다.
* **전체 요약 (Summary):** 영상이 말하고자 하는 전체적인 핵심 주제를 짧고 간결하게 요약합니다.
* **챕터별 요약 (Chapter Summary):** 영상의 구간별 주요 흐름과 세부 내용을 나누어 정리해 줍니다.
* **핵심 개념 (Key Concept):** 영상에 등장하는 어려운 전문 용어의 뜻을 사전처럼 알기 쉽게 풀어줍니다.
* **액션 아이템 (Action Item):** "그래서 이 지식을 내 삶이나 업무에 어떻게 적용할 수 있을까?"에 대해 AI가 실천 가능한 구체적 방안을 컨설팅해 줍니다.
* **파인만 기법 설명 (Feynman Technique):** 아무리 어려운 기술 내용이라도, 해당 분야를 전혀 모르는 초등학생도 이해할 수 있을 만큼 아주 쉽고 비유적인 표현으로 다시 풀어서 설명해 줍니다.
