# OpenClaw Claude CLI 연동과 성능 이슈 논의

## Brief
OpenClaw의 Claude CLI 연동 방법, 설치 자료 업데이트, 인증 토큰 및 세션 누적으로 인한 느려짐 해결책이 공유되었다.

## Key points
- OpenClaw 내부 구조를 다룬 글과 Claude CLI 관련 작업 링크가 공유되었고, 내용 난이도가 높다는 반응이 있었다.
- OpenClaw에서 Claude Max 구독 연동이 완전히 막힌 것은 아니며, 기존 OAuth 토큰 방식은 막혔지만 CLI 방식 등 우회 방법은 여전히 가능하다는 설명이 있었다.
- OpenClaw 최신 버전의 온보딩에서 Anthropic 또는 CLI 선택을 통해 연동을 시도할 수 있다는 안내가 있었다.
- Android 환경에서는 Termux를 Play Store가 아닌 F-Droid에서 설치해야 한다는 조언이 공유되었다.
- 뽀야의 OpenClaw 설치 자료가 CLI 연결 내용을 포함해 업데이트되었고, 관련 자료 링크들이 공유되었다.
- SOUL.md, USER.md, AGENT.md, MEMORY.md 같은 정체성·설정 파일 작성 사례를 찾는 질문이 있었고, bootstrap.md를 읽거나 직접 설정 파일 작성을 요청하면 된다는 답변이 있었다.
- Claude CLI 백엔드 사용 시 인증키 교체로 인한 fallback 지연과 ~/.claude/projects/ 세션 누적으로 인한 성능 저하 원인이 공유되었다.
- 해결책으로 OpenClaw의 cli-credentials.ts에서 Claude CLI keychain 읽기 실패 시 재시도 로직을 추가하고, ~/.claude/projects/ 내 불필요한 디렉토리를 백업 후 정리하는 방법이 제안되었다.

## Action items
- OpenClaw Claude 연동이 실패한 사용자는 공유된 YouTube 영상과 OpenClaw 설치 가이드를 참고해 CLI 방식으로 다시 시도한다.
- Android에서 Termux를 설치할 경우 F-Droid 버전을 사용한다.
- OpenClaw 성능 저하가 발생하면 ~/.claude/projects/ 용량을 확인하고 활성 OpenClaw 봇 디렉토리와 삭제 가능한 일회성 작업 디렉토리를 구분해 백업 후 정리한다.
- OpenClaw의 src/agents/cli-credentials.ts에서 readClaudeCliKeychainCredentials() 함수에 keychain 읽기 실패 재시도 로직을 추가하는 방안을 검토한다.
- SOUL.md, USER.md, AGENT.md 설정을 처음 작성하는 사용자는 bootstrap.md를 읽거나 에이전트에게 직접 설정 작성을 요청한다.
