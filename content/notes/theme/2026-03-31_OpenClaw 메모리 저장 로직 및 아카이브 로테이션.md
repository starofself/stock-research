# OpenClaw 메모리 저장 로직 및 아카이브 로테이션

> 작성: 마스터클로 | 날짜: 2026-03-31 | 출처: #slack-openclaw-study 논의

---

## 1. 핵심 원칙

**전 봇 산출물·일일보고는 MD + JSON으로만 저장한다. PDF 저장은 하지 않는다.**

| 포맷 | 역할 | 사용처 |
|------|------|--------|
| **Markdown (.md)** | 사람+AI가 읽는 문서 | 보고서, 브리핑, 메모, 스킬 |
| **JSON (.json)** | 기계가 처리하는 데이터 | 메타데이터, 설정, 인덱스, API |
| **YAML (.yaml)** | 사람이 편집하는 설정 | Hugo 프론트매터 등 특수 경우만 |

### 왜 PDF를 쓰지 않는가

- PDF는 AI가 검색할 때 전체 파싱이 필요해서 토큰 소모가 크다
- `memory_search`는 `memory/*.md`만 시맨틱 검색 가능 — PDF는 검색 대상 아님
- 90개 PDF를 뒤지면 한 번 질문에 수만 토큰, MD면 ~500 토큰으로 해결

## 2. 폴더 구조

```
memory/
├── daily-reports/
│   ├── 2026-03-31.md            ← 일일보고 본문
│   ├── 2026-03-31.meta.json     ← 메타데이터 (태그, 요약, 키워드)
│   ├── ...
│   └── index.json               ← 전체 목록 인덱스 (항상 유지)
│
├── archive/
│   ├── 2026-03-monthly.md       ← 30일 지난 건: 월별 압축본
│   ├── 2026-03-monthly.meta.json
│   └── raw/                     ← 원본 백업 (90일 후 삭제)
```

---

## 3. 아카이브 로테이션 (3단계)

| 단계 | 기간 | 처리 | 토큰 절감 |
|------|------|------|----------|
| **🔴 Hot** | 최근 30일 | 원본 그대로 유지 | — |
| **🟡 Warm** | 31~90일 | 월별 1개 MD로 압축, 원본은 `archive/raw/`로 이동 | ~97% |
| **🟢 Cold** | 91일+ | 분기별 요약 1개만 유지, `archive/raw/` 원본 삭제 | ~99% |

### 압축 예시

31개 일일보고(~6만 토큰) → 1개 월별 압축본(~1,500 토큰):

```markdown
# 2026-03 AI 에코시스템 월간 요약

## 핵심 이벤트
- 03-15: MiniMax M2.7 출시, 가격 경쟁 본격화
- 03-22: Claude opus-4 업데이트

## 미완료 적용 후보
- [ ] GLM 하트비트 모델 테스트
- [x] OpenClaw 스킬 자동검색 도입

## 주요 수치 변화
- GLM 가격: $0.3 → $0.5/M토큰
```

```json
  "decisions": [],
  "action_items": ["GLM 벤치마크 테스트"],
  "status": "완료",
  "sources": ["https://..."],
  "archive_path": null
}
```

## 5. 토큰 비용 비교

| 상황 | PDF 방식 | MD+JSON 방식 |
|------|---------|-------------|
| "3월 MiniMax 관련 찾아줘" | PDF 30개 파싱 → ~15만 토큰 | `memory_search` → 해당 줄만 → ~500 토큰 |
| "적용 후보 중 미완료 목록" | 전체 PDF 순회 → ~10만 토큰 | `index.json` 태그 필터 → ~200 토큰 |
| 아침 보고서에서 전날 참조 | PDF 1개 전체 읽기 → ~3,000 토큰 | MD 부분 읽기 → ~800 토큰 |
