id="SE-401ffe47-0852-4e7e-af3e-fba3fec50118" style="line-height:2.0;"><span class="se-fs-fs16 se-ff-nanumbareunhipi se-weight-unset se-style-unset" id="SE-eda6c18f-d124-4aca-ac67-c4d32c5b6ffc" style="color:#000000;">2.2.2 샌즈랩의 포지셔닝: CTI 중심의 통합 플랫폼 'CTX'</span></p><p class="se-text-paragraph se-text-paragraph-align-" id="SE-ce5bd0ba-5662-4f19-87a7-700fefc96224" style="line-height:2.0;"><span class="se-fs-fs15 se-ff-nanumbareunhipi se-weight-unset se-style-unset" id="SE-a2f31944-6a89-4320-a156-43cd86e6e195" style="color:#000000;">샌즈랩의 전략은 '인프라 통합'이 아닌 **'인텔리전스 통합'**이다. 동사의 CTX(Cyber Threat X) 플랫폼은 단순한 정보 조회 사이트가 아니라, 네트워크(MNX), 엔드포인트(MAX), 문서(MDX) 등 다양한 센서에서 수집된 데이터를 통합 분석하여 API 형태로 고객의 기존 보안 장비(방화벽, SIEM 등)에 주입하는 '두뇌' 역할을 수행한다.</span></p><ul class="se-text-list se-text-list-type-bullet-disc"><li class="se-text-list-item"><p class="se-text-paragraph se-text-paragraph-align-" id="SE-9744ab70-474b-4004-b535-5220ad641144" style="line-height:2.0;"><span class="se-fs-fs15 se-ff-nanumbareunhipi se-weight-unset se-style-unset" id="SE-c361f620-ca0f-4249-9e3b-c9da9e3101cf" style="color:#000000;">API 경제: 고객사는 별도의 하드웨어를 도입할 필요 없이, API 연동만으로 샌즈랩의 인텔리전스를 사용할 수 있다. 이는 도입 장벽을 획기적으로 낮추고, 고객의 Lock-in 효과를 강화한다.</span></p></li><li class="se-text-list-item"><p class="se-text-paragraph se-text-paragraph-align-" id="SE-bdc274cc-f351-4ee3-8fb3-3c174b3f8702" style="line-height:2.0;"><span class="se-fs-fs15 se-ff-nanumbareunhipi se-weight-unset se-style-unset" id="SE-9c6a3ad3-1b68-4f46-a825-cd2c8b1382d3" style="color:#000000;">적합성 평가: Medium-High. 글로벌 트렌드인 XDR(Extended Detection and Response) 생태계에서 'Intelligence Provider'로서의 포지셔닝은 명확하다. 다만, 팔로알토네트웍스(Palo Alto Networks)나 크라우드스트라이크(CrowdStrike)와 같은 글로벌 거대 플랫폼과 경쟁하기보다는, 이들에게 아시아 지역의 특화 데이터를 공급하는 파트너십 전략이 유효할 것으로 판단된다.</span></p></li></ul><p class="se-text-paragraph se-text-paragraph-align-" id="SE-c31b38a7-4a48-4cc8-9ca0-c1805e1924da" style="line-height:2.0;"><span class="se-fs-fs19 class="se-text-paragraph se-text-paragraph-align-" id="SE-2383e057-b28a-45d4-9a80-eb468e2ae868" style="line-height:2.0;"><span class="se-fs-fs16 se-ff-nanumbareunhipi se-weight-unset se-style-unset" id="SE-5208f057-43b3-439a-92b3-339febcdb62b" style="color:#000000;">2.3.1 트렌드 배경: 경계 없는 보안</span></p><p class="se-text-paragraph se-text-paragraph-align-" id="SE-9fc3c42a-55f3-444b-babf-755aa7da8468" style="line-height:2.0;"><span class="se-fs-fs15 se-ff-nanumbareunhipi se-weight-unset se-style-unset" id="SE-dd6d5ff2-c61b-4c74-9339-745233c239d5" style="color:#000000;">클라우드 전환과 원격 근무 확산으로 인해 네트워크 경계가 사라졌다. '제로 트러스트(Zero Trust)'는 "아무것도 신뢰하지 말고 항상 검증하라"는 원칙 하에, 사용자 계정, 디바이스 상태, 접속 위치 등을 종합적으로 판단하여 접근 권한을 부여한다.</span></p><p class="se-text-paragraph se-text-paragraph-align-" id="SE-3ca35293-4e0d-4dde-b462-ba55b7fce715" style="line-height:2.0;"><span class="se-fs-fs16 se-ff-nanumbareunhipi se-weight-unset se-style-unset" id="SE-4e3f4f4c-9b99-4be9-b594-9595ef3dc402" style="color:#000000;">2.3.2 샌즈랩의 포지셔닝: 제로 트러스트의 '판단 근거' 제공</span></p><p class="se-text-paragraph se-text-paragraph-align-" id="SE-15612598-0c05-4baa-bb2e-1d7ae3cf9c1d" style="line-height:2.0;"><span class="se-fs-fs15 se-ff-nanumbareunhipi se-weight-unset se-style-unset" id="SE-aad6ebeb-2376-4ccb-bd5c-a25c052e297e" style="color:#000000;">제로 트러스트 아키텍처에서 가장 중요한 것은 '정책 결정 지점(Policy Decision Point, PDP)'이다. 접속 요청이 들어왔을 때, 해당 디바이스가 감염되었는지, 해당 사용자가 접속하려는 서버가 악성 C&amp;C(Command &amp; Control) 서버인지 판단하려면 외부의 위협 인텔리전스가 필수적이다.</span></p><ul class="se-text-list se-text-list-type-bullet-disc"><li class="se-text-list-item"><p class="se-text-paragraph se-text-paragraph-align-" id="SE-e129ed75-17ad-4d84-9f4f-dfab9464f1ca" style="line-height:2.0;"><span class="se-fs-fs15 se-ff-nanumbareunhipi 제공하는 역할을 수행한다. 예를 들어, MNX 제품은 네트워크 트래픽을 분석하여 이상 징후를 탐지하고, 이를 제로 트러스트 정책 엔진에 전달하여 접속을 차단하게 만든다.</span></p></li><li class="se-text-list-item"><p class="se-text-paragraph se-text-paragraph-align-" se-text-paragraph-align-" id="SE-f1904b3c-e805-4e22-a198-d4fee8eb5c31" style="line-height:2.0;"><span class="se-fs-fs19 se-ff-nanumbareunhipi se-weight-unset se-style-unset" id="SE-d4202400-4be8-4073-9099-f75081fa9858" style="color:#000000;">2.4 Cloud Security: 클라우드 네이티브와 컨테이너 보안</span></p><p class="se-text-paragraph se-text-paragraph-align-" 또한 가볍고, 빠르며, 유연하게 확장 가능해야 한다(Scalability).</span></p><p class="se-text-paragraph se-text-paragraph-align-" id="SE-5d764a3c-fb8b-4713-9f7f-5aae061718a8" style="line-height:2.0;"><span class="se-fs-fs16 id="SE-a6414889-2d66-411a-91bb-aa9d2f5455fd" style="color:#000000;">샌즈랩의 MDX(Malware Document Shield) 솔루션은 설계 단계부터 도커(Docker) 컨테이너 기반으로 개발되었다.</span></p><ul class="se-text-list se-text-list-type-bullet-disc"><li class="se-text-list-item"><p class="se-text-paragraph se-text-paragraph-align-" id="SE-f9bc6ca2-90f6-4242-9094-cc32a4e83a3d" style="line-height:2.0;"><span
