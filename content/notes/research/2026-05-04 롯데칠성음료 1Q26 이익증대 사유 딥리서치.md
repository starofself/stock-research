## 1. 결론 요약

롯데칠성음료의 2026년 1분기 이익 급증은 **매출 급성장 때문이 아니라, 원가율 개선 + 판관비율 하락 + 해외 자회사 턴어라운드가 동시에 겹친 마진 레버리지 효과**로 보는 게 맞다.

- 매출은 9,525억원으로 YoY +4.6%에 그쳤지만, 영업이익은 478억원으로 YoY +91.0% 증가했다.
- 영업이익률은 2.7% → 5.0%로 +2.3%p 개선됐다.
- 손익계산서 브릿지상 영업이익 +228억원은 거의 그대로 다음 두 항목으로 설명된다.
  - 매출총이익 +265억원
  - 판관비 +37억원 증가에 그침
  - 순효과: +228억원
- 사업부별로는 해외 자회사 개선이 영업이익 증가분의 최대 축이다.
  - 음료: 영업이익 +81억원
  - 주류: 영업이익 +14억원
  - 해외 자회사: 영업이익 +137억원
  - 단순 합계 +232억원으로 연결 영업이익 증가 +228억원과 거의 일치한다.

즉, 이번 실적은 “내수 음료/주류가 폭발적으로 잘 팔렸다”보다 **해외 법인 정상화와 비용 구조 개선이 예상보다 강하게 들어온 분기**다.

## 3. 손익계산서 브릿지: 이익 증가의 직접 원인

IR 요약 연결재무제표 기준:

- 매출액: 9,103억원 → 9,525억원 / +422억원 / +4.6%
- 매출총이익: 2,952억원 → 3,216억원 / +265억원 / +9.0%
- 판매관리비: 2,701억원 → 2,738억원 / +37억원 / +1.4%
- 영업이익: 250억원 → 478억원 / +228억원 / +91.0%

핵심 포인트:

- 매출총이익률: 32.4% → 33.8% / +1.4%p
- 판관비율: 29.7% → 28.7% / -1.0%p
- 영업이익률: 2.7% → 5.0% / +2.3%p

해석:

1. 매출이 4.6% 증가할 때 매출총이익은 9.0% 증가했다.
   - 원가율이 67.6% → 66.2%로 낮아진 것으로 역산된다.
   - 원가/믹스/가격/해외 법인 수익성 정상화가 복합적으로 작용했다.
2. 판관비는 +37억원, +1.4%만 증가했다.
   - 매출 증가율 4.6%보다 낮아 판관비율이 1.0%p 하락했다.
   - LS증권 보도에 따르면 고정비, 물류비, 인건비 절감 효과가 1분기 증익을 견인한 것으로 분석됐다.
3. 따라서 1Q26 영업이익 서프라이즈는 매출 성장이 아니라 **GPM 개선 + SG&A 통제**가 만든 구조다.

## 4. 사업부별 분해

### 4.1 음료사업: 내수는 저성장, 수익성은 개선

음료사업 1Q 실적:

- 매출액: 4,082억원 → 4,142억원 / +59억원 / +1.5%
- 영업이익: 130억원 → 211억원 / +81억원 / +62.0%
- 영업이익률: 3.2% → 5.1% / +1.9%p

카테고리:

- 탄산: 2,112억원 → 2,168억원 / +56억원 / +2.7%
- 주스: 363억원 → 367억원 / +4억원 / +1.1%
- 커피: 595억원 → 601억원 / +6억원 / +1.0%
- 에너지: 226억원 → 245억원 / +20억원 / +8.7%
- 생수: 360억원 → 332억원 / -28억원 / -7.9%
- 탄산수: 109억원 → 115억원 / +7억원 / +6.1%
- 스포츠: 79억원 → 88억원 / +9억원 / +11.5%
- 내수: 3,761억원 → 3,782억원 / +21억원 / +0.6%
- 수출: 300억원 → 341억원 / +40억원 / +13.4%

해석:

- 내수 음료는 +0.6%로 거의 정체다.
- 그런데 영업이익은 +62% 증가했다.
- 탄산, 에너지, 스포츠, 탄산수, 수출 등 고마진/성장 카테고리가 상대적으로 버텼고, 비용 효율화가 붙으면서 영업이익률이 개선된 것으로 보인다.
- 생수는 감소했다. 따라서 이번 음료 실적을 단순한 전체 소비 회복으로 보면 안 된다. 카테고리 믹스와 비용 통제가 더 중요하다.

### 4.2 주류사업: 매출 정체이나 이익률 방어

주류사업 1Q 실적:

- 매출액: 1,929억원 → 1,942억원 / +13억원 / +0.7%
- 영업이익: 142억원 → 156억원 / +14억원 / +9.6%
- 영업이익률: 7.4% → 8.0% / +0.6%p

카테고리:

- 소주: 1,046억원 → 1,072억원 / +27억원 / +2.6%
- 맥주: 146억원 → 109억원 / -37억원 / -25.3%
- 청주: 251억원 → 257억원 / +7억원 / +2.7%
- 와인: 203억원 → 199억원 / -5억원 / -2.3%
- 스피리츠: 50억원 → 41억원 / -9억원 / -17.5%
- RTD: 37억원 → 65억원 / +28억원 / +74.4%
- 내수: 1,710억원 → 1,727억원 / +16억원 / +0.9%
- 수출: 219억원 → 215억원 / -3억원 / -1.6%

해석:

- 주류는 매출 성장이 거의 없다.
- 소주와 RTD는 좋지만, 맥주·와인·스피리츠가 약했다.
- 그래도 영업이익률이 0.6%p 개선됐다. 즉, 주류도 외형 성장보다는 비용/제품믹스/마케팅비 효율화로 이익 방어가 된 모습이다.
- RTD +74.4%는 작지만 의미 있는 성장 축이다. 다만 절대 매출액은 65억원 수준이라 전체를 뒤집을 규모는 아직 아니다.

### 4.3 해외 자회사: 이번 서프라이즈의 최대 축

해외 자회사 합계 1Q 실적:

- 매출액: 3,405억원 → 3,783억원 / +378억원 / +11.1%
- 영업이익: 6억원 → 143억원 / +137억원 / +2,123.0%
- 영업이익률: 0.2% → 3.8% / +3.6%p

주요 국가별:

- 필리핀
  - 매출액: 2,542억원 → 2,589억원 / +47억원 / +1.8%
  - 영업이익: -33억원 → 54억원 / +87억원
  - 영업이익률: -1.3% → 2.1% / +3.4%p
- 파키스탄
  - 매출액: 390억원 → 423억원 / +33억원 / +8.5%
  - 영업이익: 39억원 → 10억원 / -28억원 / -73.5%
  - 영업이익률: 9.9% → 2.4% / -7.5%p
- 미얀마
  - 매출액: 60억원 → 268억원 / +208억원 / +349.4%
  - 영업이익: -13억원 → 46억원 / +59억원
  - 영업이익률: -21.0% → 17.3% / +38.3%p

해석:

- 해외 자회사 영업이익 증가 +137억원은 연결 영업이익 증가 +228억원의 약 60%에 해당한다.
- 필리핀은 매출 증가가 작았지만 적자에서 흑자로 돌아섰다. 즉, 판매량보다 수익성 정상화가 핵심이다.
- 미얀마는 매출과 이익 모두 급반등했다. 매출 +208억원, 영업이익 +59억원으로 해외 턴어라운드의 두 번째 축이다.
- 파키스탄은 매출은 증가했지만 이익은 감소했다. 환율/원가/가격 통제 이슈가 남아 있는 것으로 봐야 한다.

## 5. 컨센서스 대비 왜 더 좋았나

시장 예상은 영업이익 368억원이었고 실제는 478억원이다. 초과분은 +110억원이다.

가능한 초과 원인:

1. 해외 자회사 수익성 정상화 속도가 예상보다 빨랐다.
   - 필리핀: -33억원 → +54억원
   - 미얀마: -13억원 → +46억원
   - 이 두 국가만으로 영업이익 +146억원 개선이다.
2. 판관비 통제가 강했다.
   - 매출 +4.6%에도 판관비는 +1.4%만 증가했다.
   - 판관비율은 29.7% → 28.7%로 하락했다.
3. 매출총이익률이 1.4%p 개선됐다.
   - 원가 부담이 완전히 사라진 건 아니지만, 1분기에는 매출총이익 증가율이 매출 증가율을 크게 상회했다.
4. 음료사업 수익성이 예상보다 좋았다.
   - 음료 매출 +1.5%에 영업이익 +62.0%는 명확한 마진 개선 신호다.

## 6. 외부 뉴스/증권사 관점과 연결

### LS증권 / 이데일리 보도

이데일리 보도에 따르면 LS증권은 1분기 증익 요인으로 다음을 제시했다.

- 판관비 절감을 중심으로 한 비용 효율화
- 전년도 낮은 기저
- 고정비, 물류비, 인건비 절감 효과
- 지난해 수익성 악화 요인이었던 원재료 가격 부담 완화
- 오렌지 농축액 선물 가격 전년 대비 약 50% 하락

동시에 2분기 이후 리스크로 다음을 지적했다.

- 중동 사태 장기화
- 포장재 가격 상승
- 원화 약세
- 알루미늄 선물 가격 상승분이 2~3분기부터 래깅되어 반영될 가능성

### KB증권 / 프라임경제 보도

프라임경제 보도에 따르면 KB증권은 다음을 전망했다.

- 따뜻한 날씨에 따른 음료 수요 증가
- 전년 기저 효과
- 해외 사업 개선 효과
- 필리핀 법인 흑자 전환 가능성
- 미얀마 생산 정상화에 따른 매출 증가
- 단기적으로는 캔/PET 등 포장재, 환율 상승에 따른 원재료 수입 비용 부담

실제 1Q26 결과는 이 관점과 대체로 일치한다. 특히 필리핀 흑자전환, 미얀마 급반등, 비용 효율화가 숫자로 확인됐다.

## 10. 최종 분류

롯데칠성음료의 1Q26 실적은 **해외 자회사 턴어라운드 + 비용효율화 기반의 이익률 정상화 이벤트**로 분류한다.

- 단순 매출 성장주: 아님
- 내수 소비 회복주: 아직 약함
- 비용 효율화/마진 정상화주: 맞음
- 해외 자회사 턴어라운드주: 맞음
- 리스크: 포장재·환율·중동 변수, 내수 저성장, 해외 국가별 편차

투자 해석:

- 이번 분기는 질이 나쁘지 않다. 매출이 조금 늘었는데 이익이 크게 늘어난 것은 마진 구조가 개선됐기 때문이다.
- 다만 핵심은 지속성이다. 2Q 이후에도 해외 OPM과 판관비율이 유지되면 밸류에이션 리레이팅 근거가 생긴다.
- 반대로 알루미늄/PET/환율 부담이 2~3분기에 반영되어 매출총이익률이 다시 꺾이면 1Q 서프라이즈는 일회성으로 해석될 수 있다.

## 2026-05-04 추가 메모 — 해외법인 실적 급증 원인 가설 검증

### 결론
해외법인 실적 급증은 신규 법인 편입이나 국내 공정 해외이전보다, 기존 해외 보틀링 법인의 수익성 개선 프로젝트가 2026년 1분기에 숫자로 강하게 드러난 결과로 판단한다. 특히 필리핀 PCPPI와 미얀마 법인이 핵심이다.

### 근거 요약
- 2026.1Q IR/DART: 해외 자회사 매출 3,405억 → 3,783억(+11.1%), 영업이익 6억 → 143억(+137억). 필리핀 -33억 → +54억, 미얀마 -13억 → +46억.
- 한국경제(2026-03-29): 필리핀 법인은 2024년부터 가격 조정, 고마진 제품 확대, 유통망 효율화, 물류비 절감 등 수익성 개선 작업을 추진했고 실적이 개선됐다고 보도. 미얀마 법인은 2025년 매출 800억, 영업이익 207억, OPM 25.8% 수준의 고수익 법인으로 언급.

- 디지털데일리(2026-05-04): 2026.1Q 글로벌 부문 매출 3,783억, 영업이익 143억, 필리핀·미얀마 흑자전환, 수익성 중심 경영과 사업부별 효율화가 실적으로 이어졌다고 보도.

### 해석
1. 필리핀: 2023년 종속기업 편입 이후 통제권이 커졌고, 2024년부터 가격 조정·고마진 믹스·유통/물류 효율화가 진행됐다. 2026.1Q에는 전년동기 적자였던 낮은 기저까지 겹쳐 흑자전환 폭이 크게 보였다.
2. 미얀마: CAPA/생산량 증가와 현지 고수익 구조가 결합. 2025년 이미 고마진 법인으로 확인됐고, 2026.1Q에는 전년동기 적자 기저 대비 정상화 효과가 크게 반영된 것으로 판단.
3. 파키스탄: 영업이익은 오히려 39억 → 10억으로 악화. 따라서 해외 개선은 전 지역 동반 호황이 아니라 필리핀·미얀마 집중 효과다.
4. 국내 공정 해외이전 증거는 여전히 확인되지 않음. 확인된 키워드는 가격/믹스/유통망/물류비/CAPA/효율화다.
