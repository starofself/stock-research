# AI 영상 생성 모델과 카카오톡 봇 실험 논의

## Brief
그록, 시댄스, 클링, VEO, LTX-2 등 AI 영상 생성 모델의 품질·비용·제한과 카카오톡 봇 및 인증 서비스 관련 질문이 오갔다.

## Key points
- 그록은 구독 기반으로 동영상 생성이 가능하며 무료 프로모션은 종료된 것으로 언급되었고, 보이스/TTS 품질은 좋지만 대사 입력 시 립싱크가 완벽하지 않다는 평가가 있었다.
- AI 영상 모델 티어로 시댄스가 1티어, 클링/VEO가 2티어, 그록이 3티어로 제시되었으며, 시댄스는 멀티컷, 연기, 효과음, 동작 연결, 공간지각 능력이 강점으로 평가되었다.
- VEO는 유료 사용 비용이 비싸고 사용이 번거롭다는 의견이 있었으며, 제미나이/VEO 출시 흐름이 조용하다는 말이 나왔다.
- 오픈소스 영상 모델 LTX-2가 공유되었고 시댄스급이라는 소문이 언급되었지만 실제 사용 경험은 없다는 답변이 있었다.
- 과거 제작한 유튜브 영상 사례가 공유되었고, 당시에는 미드저니와 캡컷을 활용해 인간 편집으로 품질을 냈다는 경험담이 나왔다.
- 미드저니는 과거에도 까다로웠지만 감성 표현 측면에서는 여전히 강점이 있다는 평가가 있었다.
- 카카오톡 댓글 대화가 외부 카운팅에 포함되지 않는다는 점과, 카톡 봇을 만들어 봤지만 성능이 기대 이하였다는 경험이 공유되었다.
- 류동호가 구성원 인증용 문자 인증 업체 중 개인정보 보호 측면에서 신뢰할 만한 곳이 있는지 질문했다.
- openclaw-android GitHub 저장소 링크가 공유되었다.

## Action items
- 단톡방에 영상 제작 후기 공유 요청을 검토한다.
- 구성원 문자 인증에 사용할 개인정보 보호가 신뢰 가능한 업체 후보를 조사한다.
- LTX-2와 openclaw-android 저장소를 검토해 활용 가능성을 확인한다.

## Questions
- 구성원 인증용 문자 인증에서 개인정보가 안전한 신뢰할 만한 업체는 어디인가?
- LTX-2는 실제로 시댄스급 성능을 낼 수 있는가?
- 카카오톡 댓글 대화가 카운팅되지 않는 문제를 봇이나 로그 수집에서 어떻게 처리할 수 있는가?
